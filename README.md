# Aplikasi Pencatatan Keuangan Harian Mahasiswa
Aplikasi Pencatatan Keuangan Harian Mahasiswa adalah aplikasi berbasis web yang membantu mahasiswa mencatat dan mengelola pemasukan serta pengeluaran sehari-hari.

## Fitur Utama
- Registrasi dan login mahasiswa.
- Pengelolaan kategori pemasukan dan pengeluaran.
- Pencatatan transaksi pemasukan dan pengeluaran.
- Pencarian dan filter transaksi.
- Rekapitulasi pemasukan dan pengeluaran.
- Perhitungan total pemasukan, total pengeluaran, dan saldo.

## Tujuan
Membantu mahasiswa mengelola keuangan sehari-hari agar lebih teratur dan memudahkan pemantauan kondisi keuangan.

## Teknologi
- HTML
- CSS
- JavaScript
- Database (disesuaikan dengan implementasi)

## Status Proyek
Dalam tahap pengembangan.
